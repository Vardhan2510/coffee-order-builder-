# ☕ Coffee Order Builder

An interactive coffee customization web application built using **HTML**, **CSS**, and **JavaScript**.

Users can build their own coffee by selecting different drinks, sizes, milk options, and extra toppings. The application updates the coffee cup visualization and order summary instantly while calculating the total price.

---

## 🚀 Features

- Select different coffee drinks
  - Espresso
  - Latte
  - Cappuccino
  - Matcha
  - Chai

- Choose cup size
  - Small
  - Medium
  - Large

- Select milk type
  - Regular
  - Oat
  - Almond
  - Soy
  - No Milk

- Add extras
  - Extra Shot
  - Vanilla Syrup
  - Caramel Syrup
  - Whipped Cream

- Dynamic coffee cup visualization

- Live order summary

- Automatic price calculation

- Responsive design for desktop and mobile devices

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/coffee-order-builder.git
```

2. Navigate into the project

```bash
cd coffee-order-builder
```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
